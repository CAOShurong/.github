# Code of Conduct

## Our standard

We want contributions and discussions to be welcoming, useful, and safe.
Participants are expected to:

- be respectful and assume good faith while discussing technical work;
- focus criticism on ideas, behavior, and evidence rather than people;
- explain disagreement clearly and leave room for correction;
- respect privacy, licensing, attribution, and the boundaries of each project;
- avoid harassment, discrimination, intimidation, threats, doxxing, and
  unwanted contact; and
- keep shared issue, review, and discussion spaces relevant to the project.

## Scope

This policy applies in the project's issue, pull-request, review, discussion,
and other public contribution spaces, as well as when someone is representing
the project in another public or private setting. Project-specific rules may
add requirements, but may not remove these basic expectations.

## Reporting concerns

If possible, report conduct concerns privately to the repository maintainer
through the contact route in that repository's README or GitHub profile. Do not
include sensitive details in a public issue. If no private route is available,
open an issue asking for a private contact without describing the incident or
including personal data. Security vulnerabilities must follow the target
repository's `SECURITY.md` or Security tab instead. When a repository uses
this account-wide default, its policy is documented in the [account-wide
SECURITY.md](https://github.com/CAOShurong/.github/blob/main/SECURITY.md).

Reports will be handled on a best-effort basis. There is no guaranteed response
time or private consulting service. A maintainer may remove content, limit
participation, or take other proportionate action when conduct violates this
policy. Decisions should be explained to the people directly involved when it
is safe and practical to do so.

## Attribution

This policy is an account-wide default for repositories owned by CAOShurong.
Repositories may provide a more specific policy. The standards are informed
by the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
